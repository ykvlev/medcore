# Аннотация

Курсовой проект посвящён разработке информационной системы MEDCORE для медицинских организаций города. Система автоматизирует работу регистратуры, кадровой службы и врачей: справочник больниц и поликлиник с иерархией «корпус — отделение — палата — койка», учёт сотрудников и их квалификации, регистрация пациентов и прикреплений, оформление приёмов, госпитализаций, переводов и выписок, заказ лабораторных исследований и отчётность. Доступ разграничен по шести ролям, сведения об учреждении и лечении ограничены контекстом пользователя. Все медицинские данные учебные и вымышленные.

База данных развёрнута на PostgreSQL 18.0 в схеме project и включает 48 таблиц, 3 представления, 4 хранимые процедуры, 11 функций и 12 параметризованных SQL-запросов. Целостность данных обеспечивается ключами, проверками значений, ограничениями пересекающихся интервалов и отложенными проверками согласованности событий; применены расширения btree_gist и pg_trgm.

Серверная часть разрабатывается на платформе ASP.NET Core (C#), клиентская часть — одностраничное веб-приложение на React с TypeScript; обмен данными выполняется через REST API. База данных развёрнута и проверена: три миграции применены на учебном сервере, SQL-проверки и проверка двух одновременных сессий прошли успешно. Сервер и клиент находятся в разработке, поэтому результаты их испытаний в аннотации не приводятся.

Объём пояснительной записки и приложений А–К не определён до окончательной сборки комплекта и указан как «уточняется».

Ключевые слова: информационная система, медицинская организация, база данных, PostgreSQL, ASP.NET Core, React, TypeScript, госпитализация, разграничение доступа, целостность данных.
