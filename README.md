# MEDCORE

Курсовой проект «Разработка информационной системы для медицинских организаций города» по дисциплине «Технология разработки и защиты баз данных».

- Разработчик: Яковлев Артём Сергеевич, группа 5996.
- Руководитель: Цымбалюк Лариса Николаевна.
- Срок сдачи: 11 мая 2027 года.
- Назначение: учебное локальное веб-приложение с вымышленными медицинскими данными.
- Стек: PostgreSQL 18, C# / ASP.NET Core 10, React 19 / TypeScript.

## Состав

- `database/` — миграции схемы, SQL-проверки, демонстрационные данные, двенадцать обязательных запросов.
- `backend/` — пять проектов .NET: Api, Application, Domain, Infrastructure, Tests. Схему создают только SQL-миграции; EF Core используется для чтения и обычных операций.
- `frontend/` — React-клиент: вход, обзор, организации и структура, персонал, пациенты, стационар, лаборатории, отчёты, администрирование.
- `docs/` — проектные решения, модель данных, проверки, снимки экранов и комплект документов сдачи.

## Запуск

```powershell
pnpm install --frozen-lockfile
pnpm test:database                 # изолированная PGlite-проверка SQL
node tools/run-dev.mjs             # сервер http://127.0.0.1:5180 и клиент http://127.0.0.1:5173
```

Параметры подключения к учебному PostgreSQL хранятся в локальном `.env` (в репозиторий не попадает). Демонстрационные учётные записи: `admin`, `manager`, `chief`, `deputy`, `head`, `doctor`, `registrar`, `lab`, `analyst`, `minister`, `governor`; пароль — в `.env` (`MEDCORE_DEMO_PASSWORD`).
